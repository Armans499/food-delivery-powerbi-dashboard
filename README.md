# Food Delivery Analytics Dashboard

A 3-page Power BI dashboard analysing food delivery operations, styled in a Swiggy-inspired orange and black theme.

## Pages
1. Executive Overview
2. Delivery Performance
3. Restaurant & Customer Insights

## What I did
- Cleaned messy data in Power Query (duplicates, nulls, outliers, text and date fixes)
- Built a star schema with a DAX Calendar table
- Wrote 14 DAX measures
- Added City and Month slicers synced across pages

## Key findings
- Deliveries are slowest at lunch and dinner peak hours
- July and August show a clear rise in delayed orders
- Delivery time increases steadily with distance
- Delayed orders receive lower customer ratings

## Files
- `Food_Delivery_Dashboard.pbix` - Power BI file
- `data/` - CSV files
- `docs/` - dashboard PDF and full documentation
- `screenshots/` - dashboard screenshots

## Note
The dataset is synthetic and was created to model realistic food delivery operations. It is not real company data.
